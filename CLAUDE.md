# TS Gettext Extractor

A Rust CLI (published to npm and crates.io) that generates Gettext template files (`.pot`) from JavaScript/TypeScript/Astro code, using SWC to parse. See [README.md](README.md) for usage and supported functions.

## Releasing

See [RELEASE.md](RELEASE.md): `yarn bump patch|minor|major` then `git push --follow-tags`.
